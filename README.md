# EBAZ4205-Experiments
Experiments and hacks using EBAZ4205 and an Adapter board.

Extra 2 FPGA signals modification
=================================
This provides a valuable extra two FPGA signals for user applications,
e.g. as an I2c bus, or for a UART etc.

FPGA Reset button modification
==============================
This provides a reset button signal input to the FPGA for user applications.
If U30 is fitted, this mod replaces the ACGI voltage monitor output signal.
